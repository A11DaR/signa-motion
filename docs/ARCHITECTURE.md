# Карта исходного кода SIGNA

Исходники расположены в `src/`, страница и стили — в корне, сторонние ресурсы — в `public/`. `npm run build` копирует их в готовый каталог `dist/`; он не хранится в Git. Модули разделены по ответственности; файл `src/main.js` связывает их с DOM. Библиотека и модель явно отделены от собственного кода в `vendor` и `models`.

## Камера и изображение

| Путь | Ответственность |
| --- | --- |
| `src/vision/camera.js` | Разрешение камеры, загрузка модели, GPU/CPU, отмена подключения и освобождение ресурсов |
| `src/vision/tracking.js` | Единственный цикл кадров, ограничение частоты, запрет параллельного inference, оценка яркости |
| `src/ui/viewport.js` | Единая геометрия вписывания видео и скелета без растяжения |
| `src/vision/calibration.js` | Короткая настройка видимости и рабочего размера ладони |

## Собственное распознавание

| Путь | Ответственность |
| --- | --- |
| `src/vision/landmarks.js` | Преобразование 21 точки в углы, расстояния, форму пальцев, ориентацию и локальную плоскость кисти |
| `src/gestures/gesture-rules.js` | `detectGesture`, `validateGesture`, `getGestureErrors`: правила формы, оценка соответствия и конкретные исправления |
| `src/gestures/stability.js` | Накопление подтверждённого времени удержания с допустимыми краткими пропусками |
| `src/gestures/wrist-nod.js` | Движение YES: кивок в локальной плоскости, возврат и удержание |
| `src/gestures/recognizer.js` | Порядок фаз ILY/YES/NO, сброс при длительной потере, одноразовое событие `success` |
| `src/lesson/feedback.js` | Стабилизация текста подсказок и подсчёт устойчивых ошибок |

Углы измеряются в градусах, внутренние расстояния нормализованы по размеру ладони. YES измеряется относительно самой кисти, а не одной плоскости камеры. NO проверяет касание обоих кончиков в 3D, на изображении и относительно исходного раскрытия. Готовый GestureRecognizer с названиями жестов не используется.

## Урок, управление и прогресс

| Путь | Ответственность |
| --- | --- |
| `src/lesson/course.js` | Инструкции и источники; задания ILY → YES → NO; фраза YES → ILY; состояния, переходы и итоговая статистика |
| `src/navigation/navigation.js` | Режим курсора, щипок, возврат к учебному жесту |
| `src/navigation/commands.js` | Две ладони для паузы, два кулака для образца; защита от повторного срабатывания |
| `src/lesson/progress.js` | Сохранение завершённых уроков, миграция прежних рекордов, история пяти прохождений, лучшие показатели |
| `src/ui/results.js` | Разметка итогов, истории, рекордов и достижений |

## Цепочка успешного жеста

1. `CameraSession` открывает видеопоток и модель.
2. `FrameTracker` передаёт новый кадр в Hand Landmarker.
3. `extractFeatures` вычисляет признаки из landmarks.
4. `GestureRecognizer` проверяет форму и временные фазы.
5. После требуемого подтверждённого времени выдаёт `success` ровно один раз.
6. `Course.accept` фиксирует `completed` и назначает переход через 800 мс.
7. Независимый цикл интерфейса вызывает `Course.advance`, даже без новых кадров.
8. После пяти проверок показываются результаты; `src/lesson/progress.js` сохраняет одну запись.

Форма, время удержания, зачёт и переход — разные состояния. Курсор и учебный режим также разделены: управление сайтом не даёт учебный зачёт.

## Поддерживающие файлы

- `scripts/serve.mjs` — локальный HTTP-сервер.
- `scripts/check.mjs` — синтаксис, существование импортов, DOM-ссылки и локальные ресурсы.
- `tests/*.test.mjs` — поведенческие проверки; карта находится в `TESTING.md`.
- `tests/*landmarks.json`, `tests/calibration-palm.json` — численные результаты модели со ссылками и хешами исходников; фотографии не распространяются.
- `.openai/hosting.json` — конфигурация уже существующей публикации Sites. Для `npm start` и GitHub Pages она не требуется.

Нейросеть и WASM сторонние. Правила, временные автоматы, ошибки, сценарий, управление и интерфейс написаны в рамках проекта с помощью Codex; источники указаны в `THIRD_PARTY.md`.
