# Проверка SIGNA

## Автоматическая проверка

```bash
npm ci --ignore-scripts
npm test
npm run check
```

На версии приложения `3c6e084995892ad03355e5210ee4c0462e1cb18b` пройдены 75 тестов. После переноса исходников в `src/` все 75 тестов пройдены повторно. Правила и поведение сохранены; изменились пути импортов и ресурсов. Сборка проверяет готовый пакет `dist/`.

| Проверка | Файлы |
| --- | --- |
| ILY, YES, NO; неправильные варианты; удержание, потери кадров, одноразовый зачёт | `recognizer.test.mjs`, `motion.test.mjs`, `photo-recognition.test.mjs` |
| Запуск, разрешения, отмена, остановка, отсутствие параллельного inference | `camera.test.mjs`, `startup.test.mjs` |
| Калибровка, расстояние, края, освещение | `calibration.test.mjs` |

| Курсор, щипок, возврат к уроку | `navigation.test.mjs` |

Имена файлов в таблице относятся к папке `tests/`.

## Что означают результаты

DOM-тесты выполняют настоящий код интерфейса в jsdom. Видеоустройство и нейронный inference заменены контролируемыми объектами. Ошибки виртуальной консоли и необработанные события окна проверяются, но это не настоящая консоль браузера.

MediaPipe отдельно обработал учебные фото ILY, положения YES/NO и четырёхкадровую учебную GIF NO, включая отражения. Результаты записаны в JSON и используются как регрессия. Синтетические точки дополнительно проверяют разные ракурсы кивка. Это небольшая контрольная выборка, не статистическая оценка точности на людях.

## Ручная проверка перед сдачей

Результаты ниже **не заполнены автоматически**. Выполните их с настоящей камерой; отмечайте только реально проверенное.

- [ ] Чистая копия запускается по README; при отказе доступа появляется понятная подсказка и повторный запуск работает.
- [ ] Открытая ладонь проходит калибровку; частично скрытая кисть получает корректную подсказку.
- [ ] ILY: согнутый мизинец не засчитывается, после исправления есть прогресс и переход.
- [ ] YES: неподвижный кулак не проходит; плавный кивок вниз и обратно проходит без остановки внизу.
- [ ] NO: закрытые пальцы без исходного раскрытия не проходят; раскрытие → подсказка → смыкание проходит.
- [ ] Правая и левая руки проверены по отдельности.
- [ ] Краткая потеря руки сохраняет прогресс; длительная потеря сбрасывает незавершённое действие.
- [ ] Две руки не засчитываются случайно как учебный жест.
- [ ] После каждого зачёта переход автоматический; итог показывает 3 жеста и 5 проверок.
- [ ] Ладонь включает курсор, щипок нажимает, кулак возвращает к уроку; повтор доступен рукой.
- [ ] Видео и скелет совпадают при изменении окна и повороте телефона.
- [ ] Звук включается кнопкой и звучит после зачёта.
- [ ] История сохраняется после обновления страницы; при запрете хранения урок завершается.
- [ ] Публичная ссылка открывается без аккаунта владельца на другом устройстве.
