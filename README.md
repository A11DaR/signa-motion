# SIGNA — говори руками

**ADMIT Hackathon · MOTION: камера вместо джойстика**

Веб-тренажёр трёх жестов американского жестового языка (ASL). Обычная камера отслеживает кисть, собственные правила проверяют форму и движение, а приложение объясняет конкретные ошибки и автоматически ведёт пользователя до результата.

**Сценарий:** камера → калибровка → I LOVE YOU → YES → NO → фраза YES + I LOVE YOU → результаты и личный прогресс.

Это учебный прототип, не универсальный переводчик и не курс РЖЯ. Внешние материалы и использование Codex раскрыты в документации.

## Запуск за минуту

Требуется **Node.js 20+** и браузер с веб-камерой и WebAssembly SIMD.

```bash
npm start
```

Откройте **http://localhost:3000** и разрешите камеру. Для запуска не нужны `npm install`, ключи API или сервер нейросети: MediaPipe, модель и WASM уже находятся в `public/`. Команда запуска сама формирует `dist/`. Не открывайте HTML двойным щелчком.

После `npm run build` готовый `dist/` можно раздать также через Python:

```bash
python3 -m http.server 3000 --directory dist --bind 127.0.0.1
```

На телефоне требуется HTTPS-адрес. Адрес компьютера вида `http://192.168...` не заменяет HTTPS для доступа к камере.

## Собственная логика и режим «Ошибка»

MediaPipe возвращает **21 точку кисти**, а не готовые ответы ASL. Наш код проверяет углы пальцев, нормализованные расстояния, ориентацию ладони и движение во времени.

| Жест | Что требуется | Конкретное исправление |
| --- | --- | --- |
| I LOVE YOU | Большой, указательный и мизинец раскрыты; средний и безымянный согнуты; удержание 700 мс | «Выпрями мизинец», «Согни средний палец» |
| YES / «Да» | Кулак, плавный кивок кистью и возврат, затем удержание 500 мс | «Положи большой палец поверх кулака», «Кивни кистью вниз, а не вбок» |
| NO / «Нет» | Подтверждённое раскрытие двух пальцев, затем их смыкание с большим и удержание 500 мс | «Держи указательный и средний рядом», «Коснись большого обоими пальцами» |

Состояния **«Исправь жест» → «Почти» → «Верно»**, скелет, подсветка проблемных пальцев и шкала удержания показывают результат. Краткие пропуски не обнуляют прогресс. Зачёт срабатывает один раз; переход выполняется через 800 мс, даже если новые кадры больше не приходят.

## Управление рукой и бонусы

После системного разрешения камеры основной урок проходится без касаний. Открытая ладонь включает курсор, щипок нажимает, кулак возвращает к упражнению. Команды отделены от учебной проверки; начальная форма текущего жеста возвращает пользователя к уроку.

Бонусы: собственная логика распознавания, последние пять прохождений, личные рекорды каждого жеста, достижения, звук успеха, визуальные эффекты, мобильная компоновка и смена камеры. Прогресс сохраняется локально; видео не записывается и не отправляется на сервер.
