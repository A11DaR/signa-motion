# SIGNA — говори руками

Вводный интерактивный урок американского жестового языка (ASL) для **ADMIT HACKATHON / MOTION**. Обычная веб-камера становится контроллером: пользователь повторяет жест, видит распознанные суставы, получает конкретное исправление и собирает короткую фразу.

**Это прототип с тремя учебными жестами, не универсальный переводчик. ASL и РЖЯ — разные языки.** Для дальнейшего расширения словаря нужна проверка носителем или преподавателем ASL.

## Быстрый запуск

Нужен Node.js 20 или новее. Установка npm-пакетов, ключи API, сервер распознавания и платные API не требуются. MediaPipe, WASM и модель уже включены в `dist`. Нужен современный браузер с WebAssembly SIMD; устаревшие браузеры без SIMD получат подсказку об обновлении.

```bash
npm start
```

Откройте **http://localhost:3000** в браузере и разрешите доступ к камере. Не открывайте `index.html` двойным щелчком: для камеры и загрузки модели нужен HTTP на localhost либо HTTPS.

Другой вариант, если есть Python 3:

```bash
python3 -m http.server 3000 --directory dist --bind 127.0.0.1
```

Для использования на телефоне загрузите содержимое `dist` на HTTPS-хостинг. Адрес вида `http://192.168...` не даёт защищённый контекст для камеры. Сборка не нужна. Все пути относительные: приложение может работать и в подпапке.

## Законченный сценарий

1. Пользователь включает камеру и даёт системное разрешение.
2. Проходит три задания: I LOVE YOU → YES → NO. Справа — схема, инструкция и образец ASL University. Камера показывает скелет руки; проблемные пальцы выделены тёплым цветом.
3. Выполняет задание **«Да. Я тебя люблю!»**: сначала YES, затем I LOVE YOU. Проверяется заданная последовательность, а не произвольная речь.
4. Получает учебные баллы, время активной практики, число устойчивых подсказок для каждого жеста и рекомендации для повторения.
5. Может начать заново движением руки. Лучший результат хранится только в текущем браузере.

Учебные жесты можно выполнять любой рукой. В кадре должна быть одна рука; две используются только для отдельных команд интерфейса.

## Жесты и правила

| Учебный жест | Проверка | Результат |
| --- | --- | --- |
| I LOVE YOU | Большой, указательный и мизинец раскрыты; средний и безымянный согнуты; ладонь фронтально к камере; удержание 1 с | Изученный знак и соответствующая часть фразы |
| YES | Кулак; изменение наклона кисти относительно запястья; возврат в исходное положение | Подтверждение «Да» и первая часть фразы |
| NO | Безымянный и мизинец согнуты; раскрытые указательный и средний рядом; затем оба кончика смыкаются с большим | Отрицание «Нет» и завершение изучения словаря |

Для NO выбран вариант с одним смыканием. Допустимые варианты и контекст см. в словаре: приложение не оценивает все варианты ASL.

### Три разных движения для трёх действий интерфейса

Эти команды **не преподаются как ASL**:

| Движение | Действие |
| --- | --- |
| Одна открытая ладонь, 0,4 с | Включает режим курсора. Начальная позиция руки становится центром управления; небольшие перемещения достигают краёв экрана |
| Щипок большого и указательного пальцев | Нажимает кнопку или ссылку под курсором; удержание курсора 1,2 с — альтернативное нажатие |
| Курсор у верхнего / нижнего края | Прокручивает страницу либо открытый диалог |
| Один кулак, 0,5 с | Выключает курсор, закрывает образец и возвращает к упражнению |
| Две открытые ладони, 1,2 с | Пауза / продолжение урока |
| Два кулака, 1,2 с | Открывает / закрывает образец текущего жеста |

Системное разрешение камеры подтверждается обычным способом — браузер не позволяет приложению самостоятельно разрешить доступ. Дальнейший сценарий внутри SIGNA доступен без клавиатуры и мыши. В режиме курсора учебные жесты не оцениваются: сожмите кулак или выберите «К уроку», чтобы продолжить. Случайный одиночный кадр с открытой ладонью не включает курсор. После нажатия отведите курсор от кнопки, чтобы нажать её повторно. Кнопки управления видео находятся под образцом и также доступны рукой. Ссылки на внешний словарь открывают другой сайт, на который управление SIGNA не распространяется.

## Твист: режим «ошибка»

`dist/recognizer.js` вычисляет собственные признаки из 21 точки каждой руки: углы суставов, отношение расстояний к ширине ладони, направление кисти, расстояние до большого пальца и историю движения.

Ошибки разделяются:

- **Положение пальцев:** «Выпрями мизинец», «Согни средний палец к ладони», «Отведи большой палец в сторону». Проблемная группа суставов подсвечивается.
- **Движение:** «Кивни кулаком вниз и обратно», «Теперь верни кисть в исходное положение», «Коснись большого обоими пальцами».
- **Условия наблюдения:** «Кисть выходит из кадра», «Поднеси руку ближе». Это не записывается как ошибка выполнения.

Подсказки формы появляются после 450 мс стабильного результата; в статистику попадает только подсказка, сохранявшаяся 1,6 с. Мгновенные переходы не штрафуются. Для I LOVE YOU учитывается одна секунда подтверждённого положения. Краткое дрожание классификации до 350 мс приостанавливает накопление, а не обнуляет его; ошибочные кадры не прибавляют прогресс. При потере руки, смене задания, паузе и промежутке между кадрами более 1,2 с история распознавания сбрасывается. Камера с частотой 3 кадра/с может завершить удержание. Следующее задание и подпись над камерой обновляются сразу после зачёта; таймер анимации на переход не влияет. Защита от повторного зачёта длится 1,2 с. Неподвижный кулак не засчитывается как YES; закрытый щипок без предварительного раскрытия не засчитывается как NO.

В интерфейсе проценты означают **прогресс выполнения текущего правила**, не вероятность нейросети и не точность владения языком. Итоговые баллы: `max(50, 100 − 3 × число устойчивых подсказок)` после полного завершения. Это игровая метрика.

## Технологии и собственная логика

- HTML, CSS, JavaScript ES modules: без сборщика и фреймворка.
- MediaPipe Tasks Vision **0.10.32**, Hand Landmarker `float16/1` — только определение суставов.
- Собственные геометрические правила, временные автоматы для YES и NO, проверка последовательности, подсказки, команды интерфейса и курсор.
- GPU с резервным CPU-режимом; оба используют локальную SIMD-версию WASM. Обработка ограничена примерно 14 кадрами/с. В этой версии inference синхронный на основном потоке; на слабом устройстве возможны задержки.
- Видео сохраняет исходное соотношение сторон. Передняя камера и скелет зеркальны вместе, задняя камера не отражается. Кнопки вынесены под изображение, чтобы не закрывать руку. Canvas и видео используют одинаковую область вписывания.
- Canvas: скелет поверх видео и анимированная учебная схема. Схема условная, для контекста есть образцы автора учебного материала.
- Web Audio: короткий звук успеха, включается пользователем.
- `localStorage`: лучший результат на этом устройстве. Запрет хранилища не мешает пройти урок.
- Русский интерфейс, адаптивная компоновка, смена передней/задней камеры, диалоги и обычные кнопки как дополнительный способ управления.
- Необязательный WebMCP: чтение состояния и перезапуск урока. Он не может засчитать жест или создать результат без камеры.

Видео камеры не записывается и не отправляется в сеть. Модель и WASM загружаются с того же сайта. Образцы YouTube / иллюстрация Lifeprint запрашиваются только при открытии образца.

## Проверка

```bash
npm ci --ignore-scripts  # jsdom нужен только для проверки интерфейса
npm test
npm run check
```

Автоматические проверки покрывают полный путь «координаты суставов → распознавание → следующий экран → сохранённый результат», включая весь урок и фразу. Отдельно проверяются дрожание, 3 кадра/с, потеря руки, ложные совпадения, порядок движения, пауза, баллы, геометрия камеры, щипок, повторные нажатия, прокрутка, модальные окна, управление учебным видео и возврат к распознаванию. YouTube API в тесте заменён контролируемым объектом; доступность внешнего видео этим не подтверждается.

**Предел проверки:** тесты используют синтетические суставы/признаки. Они проверяют нашу логику, но не измеряют точность нейросети на реальных людях. Доступа к физической веб-камере и разрешённой среде браузерного тестирования при создании не было. Реальная камера, отображение в браузере, производительность на телефоне и WebMCP нуждаются в ручной проверке перед сдачей. Нельзя заявлять процент точности распознавания на основании этих тестов.

Минимальный ручной прогон:

1. Разрешить и отдельно запретить камеру, проверить восстановление.
2. Пройти весь урок до результата обеими руками по очереди.
3. Проверить конкретные ошибки: согнутый мизинец для ILY, неподвижный кулак для YES, закрытый щипок для NO.
4. Убрать руку на полсекунды: старое движение не должно завершиться после возврата.
5. Пройти фразу в неправильном порядке: следующий знак не должен засчитаться.
6. Включить курсор ладонью, нажать щипком, прокрутить страницу, открыть / закрыть образец и вернуться кулаком. Проверить паузу двумя ладонями, образец двумя кулаками и повтор урока рукой.
7. Проверить Chrome/Edge на ноутбуке и Chrome/Safari на телефоне при хорошем освещении.

После реальных испытаний пороги в `recognizer.js` можно адаптировать. Модель может ошибаться при перекрытии пальцев, плохом освещении, сильном наклоне или необычной моторике. Мимика и грамматика не анализируются.
